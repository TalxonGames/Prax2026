# Školská prax 2026 – Vývoj webu a Figma

Tento repozitár slúži ako prehľad mojej práce a pokrokov počas tohtoročnej školskej praxe. Hlavným cieľom je naučiť sa pracovať v dizajnovom nástroji **Figma** a následne vytvoriť **základnú webovú stránku**.

---

## 🎯 Ciele projektu

*   **Figma:** Naučiť sa základy UI/UX dizajnu, prácu s komponentmi a tvorbu wireframov.
*   **Web development:** Preklopiť hotový grafický návrh z Figmy do čistého kódu.
*   **Git:** Správne manažovať verzie kódu a dokumentovať svoj postup.

---

## 💻 Použité technológie a nástroje

*   **Dizajn:** Figma
*   **Frontend:** HTML5, CSS3 (prípadne JavaScript)
*   **Verziovanie:** Git / GitHub

---

## 📂 Štruktúra projektu

*   `/design` – Exportované dizajny, screenshoty z Figmy alebo odkaz na Figma projekt.
*   `/src` – Zdrojové kódy webovej stránky (HTML, CSS).
*   `README.md` – Dokumentácia k projektu.

---

## 🚀 Postup práce

### 1. Fáza: Návrh a Figma (Aktuálne)
*   [x] Zoznámenie sa s prostredím Figma
*   [ ] Tvorba wireframu (rozvrhnutie prvkov)
*   [ ] Finálny vizuálny návrh základnej stránky

### 2. Fáza: Kódovanie webu
*   [ ] Príprava HTML štruktúry
*   [ ] Stylovanie pomocou CSS (responzívny dizajn)
*   [ ] Kontrola chýb a validácia kódu
